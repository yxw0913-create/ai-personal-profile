# 记忆运行规范 v1.2（Muse 记忆体 · 现行宪法）

> 定案：2026-11-08 晚，用户批准《记忆系统结合优化方案 v2.0》后即行建立。
> 原则：因陋就简、能不花钱就不花钱、用现成的；好想法马上提、马上改、马上用；方法迭代对齐全球最新实践。
> 本规范只做一件事：宣布既有存储各归其位、按同一套规则运行——不另建数据库、不新购服务。

## 一、记忆体构成（全部现成资产，零新增成本）

| 层 | 载体（现成） | 职责 |
|---|---|---|
| L1 原始层 | 对话记录、每日日志 `~/memory/YYYY-MM-DD.md`、用户上传文件、照片小票 | 只增不改，冷存溯源，不进日常调用 |
| L2 结构层 | 决策登记表、关键时间线登记表（本目录）；人物档 `~/memory/people/`；各业务台账（财务总账、协作总册、收支表、子账户台账等） | 结构化登记，一事一处记全量 |
| L3 核心层 | `~/MEMORY.md`（每次会话全量注入）＋ `~/PROACTIVE_PREFERENCES.md` | 只收改变长期状态的事实与偏好，常驻精简 |
| L4 智慧层 | 后台夜间综合（对齐综合）、既有定时节律（09:00 清单、周复盘、健康小结）、Muse 临场检索关联 | 提炼、提醒、决策前关联（R6） |
| 后端重活 | 用户 DeepSeek Harness（Flash 约 99%，不足升 Pro） | 历史全量回填、季度重整等批量作业，Muse 验收 |

外部存储（用户的云盘/外设等）：需要扩容或备份时优先调用，接入前由用户点名，不擅自上传。

## 二、运行规则

- **写入**：执行方案 v2.0 的 R1–R5（日结、决策登记、偏好、项目节点、技能修正）。
- **调用**：R6——重大决策或花钱之前，先查登记表与相关档案，摊开历史依据再决定。
- **断舍离**：活跃层（L2–L4）强行淘汰约 80–90% 的过程性垃圾（闲聊、无结论试探、失效中间稿）；原始层只冷存、不调用。数字、日期、金额、用户关键原话永不压缩丢弃；被推翻的决定标状态、不删行。
- **单一事实源**：同一事实只在一处记全量，其他文件只留指针；发现两处口径不一致，当场以最新用户确认修正并留痕。
- **体检**：每月第一个周日做一次记忆体检（提议制）：核心层瘦身检查、登记表状态巡检、过期事项归档清单——只出清单，用户点头才动。
- **方法巡检**：每季度对照一次全球 Agent 记忆领域的最新公开做法（分层记忆、强压缩、主动调用等），有可借鉴的当场提出、当场并入本规范升版。

## 三、心流窗口机制（2026-11-10 转正，自《心流窗口机制 v0.1》草案并入）

用户的心流是全系统最稀缺的算力：进入心流时判断准确且高产。故判断题不散点滴问，一律攒进窗口批量过。

- **窗 A · 判定爆发窗（10–15 分钟）**：默认晨间待办清单之后 09:30 开窗；待批队列 ≥10 题时可选加开 13:00 一窗。每题预消化到一屏：问题＋选项＋标注推荐，用户连点带答，答案当场登记销账。每轮 15 分钟内答完（2026-11-09 纪律）；未答完的题不丢，下轮重列并附三个建议答案供点选，或用户自答。
- **窗 B · 睡前深迭代窗（约 30 分钟，23:00 前后）**：只做播种——用户口述目标、边界、好坏标准；夜间由 AI 迭代 3–5 个版本（批量起草走 DeepSeek Harness、Muse 收敛），次晨只交一页「版本差异＋推荐」，不堆全文。
- **分工**：时效题、一键题走手机随问随答，不进窗口；深迭代题只进窗 B，不占用白天。
- 配套：《异步协同与夜间运行机制》仍为草案，其转正另行裁决，不随本节生效。

## 四、异步协同与夜间运行机制（2026-11-10 转正，自《异步协同与夜间运行机制 v0.1》草案并入）

机器不闲着，人不被打扰。夜间与碎片时间的自动运行守四条用户裁定（2026-11-10 点选）：

- **只跑已授权任务**：夜间只执行用户已授权的确定性任务（定时简报、巡查、盯盘、已立单的跟进），不自开新课题；新想法只登记，天亮后呈报。
- **巡逻唤醒**：常设层是脚本巡逻（近零成本）；只有巡逻发现事件（价格触发、来信、状态变化）才逐级唤醒模型——整理级用 Flash、决策级才动 Muse。贵的大脑只在决策点开机。
- **报告随到随报**：自动运行的产出不限量、随到随报（用户 2026-11-10 选 B，取代草案的队列上限口径）；分级不变——SSS/S 级走即时通道，A/B 级并入晨间简报与待办清单呈现，不逐条打断。
- **成本纪律**：每个夜间任务设 token 预算上限；每周日在全流程复盘里报一行后台成本，超支的任务先降频再议存废。
