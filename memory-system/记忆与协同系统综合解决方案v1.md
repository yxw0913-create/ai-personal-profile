# 记忆与协同系统 · 综合解决方案 v1

> 汇总：2026-11-08 一夜的四份成果——《记忆系统结合优化方案 v2.0》《记忆运行规范 v1》《异步协同与夜间运行机制 v0.1》《心流窗口机制 v0.1》。
> 用户定调：没有高密级资料上云的顾虑（信用卡等保密信息本就不进记忆体）；**能云端就云端、能免费就免费、因陋就简用现成**。

## 一、部署匹配表（云端 / 本地 / 免费口径）

| 组件 | 跑在哪 | 为什么 | 成本 |
|---|---|---|---|
| 记忆文件层（MEMORY、登记表、台账） | Muse 云端 | 随总控走、换设备不丢、多端可达 | 现有订阅内 |
| 索引检索、夜间综合、主动投递 | Muse 云端（平台后台） | 平台内建能力，不另搭 | 现有订阅内 |
| 定时节律（晨报/清单/周建议/复盘） | Muse 云端（定时任务） | 用户睡着也照跑 | 现有订阅内 |
| 总控判断、题包预消化、终审 | Muse（手机端） | 用户在哪，总控在哪 | 现有订阅内 |
| 批量推演、夜间多版迭代、历史回填 | **用户本地桌面** DeepSeek Harness | 活重、量大；Flash 单价低且 key 自备全控 | 按量付费，量级为分角 |
| 冷备份（可选） | 用户自己的云存储/外设 | 记忆体副本一份在用户手里，防极端情况 | 用现成空间，0 新增 |
| 凭证与支付信息 | Secure Vault（平台保险柜） | **永不进记忆体、永不进任何登记表** | — |

结论：整套系统**不需要新购任何服务、不需要本地常开服务器**；唯一的本地角色是已有的 Harness 台式机，且只在派活时开机干活。
