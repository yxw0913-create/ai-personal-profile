# 关键时间线登记表（模板）

> 这是模板：只保留结构与规则，示例行均为虚构。真实登记表是私人档案，永不进入公开仓库。

## 用途与规则

- 用途：把散在各档案里的「未来日期与窗口」收成一处——到期日、谈判窗口、约定节点，一眼看全。
- 事项成立即登记；状态变化即更新；过期未办的标「已过期待议」，不悄悄消失。
- 按时间分段维护：近期（本季）/ 中期（本年）/ 远期。
