> 本仓库是我的个人档案入口，供我使用的各个 AI 助手（以及未来的我）在开始协作前快速了解我。

> ⚠️ **隐私红线（本仓库为公开仓库）**
> - 只写可以公开的信息：背景概要、习惯偏好、工具栈、公开项目与长期目标。
> - **绝不写入**：身份证件号码、手机号/住址等联系方式、账号密码与密钥、财务与债务明细、家人隐私、未公开的商业条款。
> - 拿不准能不能公开的内容，先不开 Issue 讨论，不要直接写进文件。

## 待办跟踪

- 本仓库的 **Issues** 即待办清单：新增待办、档案待补项、待确认问题都开 Issue 记录，用标签区分 `todo` / `profile` / `question`。
- Projects 看板（如启用）按「待办 → 进行中 → 已完成」三列跟踪同一批 Issue。

## 版本记录

- 本仓库由 Git 管理，**每次修改都是一次提交（commit），可追溯、可回退**。
- 重要变更同步记入 [CHANGELOG.md](CHANGELOG.md) 一行：日期＋改了什么。
- 回退方法：在提交历史中找到目标版本，用 `git revert <commit>` 生成反向提交，或向你的 AI 说明「回退到某月某日的版本」由它操作。

## 维护约定（给所有 AI 的操作规则）

1. 修改前先读最新版本（先 `git pull`），避免多端覆盖冲突。
2. 一次提交只做一件事，提交信息写清「改了哪节、为什么」。
3. 拿不准真实性的内容标注「待确认」，不要把推测写成事实。
4. 涉及隐私红线的内容一律拒绝写入公开仓库，建议改存私有渠道。
