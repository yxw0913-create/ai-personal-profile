# 决策登记表（模板）

> 这是模板：只保留结构与规则，示例行均为虚构。真实登记表是私人档案，永不进入公开仓库。

## 规则

- **R2（即时登记）**：决策成立即登记一行——日期 | 决策 | 依据（一句） | 状态 | 取代关系。
- **R6（先查后决）**：重大决策或花钱之前，先查本表与相关档案，把历史依据摊开再决定。
- 状态取值：生效 / 待确认 / 已被取代（注明被哪条取代）。被取代的只改状态、不删行——保留沿革，才能复盘「当时为什么这么定」。
- 数字与用户原话不压缩、不改写；叙事性内容可以摘要。
