## 入库流水线（每份资料四步）

1. **原文归档**：原文一字不改存入原始层（L1），本索引登记来源路径——单一事实源，不复制正文。
2. **提炼**：出一页要点：核心主张、可操作方法、与现有体系的关联点。
3. **分类入库**（按内容归层）：
   - 方法论/世界观类 → 《纲领》与运行规范的修订素材；
   - 工具技巧类 → 技能库（custom-skills）或作战手册；
   - 项目情报类 → 对应项目的 IN 包；
   - 判断与裁决类 → 决策登记表；
   - 人物/机构信息类 → 人物档/机构档。
4. **冲突处理**：与既有定案冲突的，单独列出请用户裁决，不擅自覆盖（沿用既有纪律）。
