## 同步约定（保持最新）

- 本目录是私有源文件的**脱敏同步版**：源文件每次升版/修订，同步更新此处对应文件，并在仓库 CHANGELOG.md 记一行。
- 脱敏口径：真实人名、机构名、金额、日期细节、联系方式一律替换为通用表述或移除；方法、结构、规则原文保留。
- 登记表类只同步模板（结构＋规则），内容永不同步。
