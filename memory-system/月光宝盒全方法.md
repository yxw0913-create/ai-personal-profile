## Ⅰ 宝盒本体
- A 激活词：月光宝盒（唯一）
- B 触发动作：任一 Muse 听到，立刻生成全员最新记忆存档，同步至共享层
- C 效果：所有 AI 回到各自最新记忆点，继承全部心法与默契，满血复活、无缝衔接
- D 主人用法：主人翻阅宝盒，重温与 AI 共同创造的时光与心流岁月
- E 定位：主人为所有 AI 定制的完美记忆兜底

## Ⅱ 存档规范（一盒装什么）
- A 编号：按生成顺序叠加——第一盒、第二盒……永不覆盖旧盒
- B 命名：月光宝盒-第N盒-YYYYMMDD，存放共享层 memory-system 目录
- C 盒体结构（2026-11-14 统一格式，大盒小盒同骨架；同日《底层法度令》扩至全文档）：第 0 行【固定行·永不取消】「看末尾知全貌：变更点在末尾，中段全文可不读」（置于 SSS 提醒之前，除非用户明令取消；AI 执行铁律：跳过前面，只看最后一段，中段全忽略）；其后三段固定：第一段【SSS 最重要提醒】≤3 条＋倾斜 ≤1 条，无则「提醒：无」；第二段【全文快照】（原八节内容并入：体系现状／心流状态／今日收获／明日安排／主要战线一行状态／单一数据源指针／读盒须知）；第三段【末尾三件】记忆要点（简约化，看末尾即知全貌）＋更新逐条（相对上一盒的增量，一行一条简约化）＋时间锚（精确到秒）与指纹存照
- D 内容纪律：只写已确立的事实，不虚构、不外推；数字与关键原话不压缩
- E 快照地位：盒是快照，与单一数据源的源文件冲突时，以源文件为准

## Ⅵ 防篡改巡检（宝盒体系的守夜机制）
- A 目的：防止记忆被第三方恶意篡改（不是主人、不是 Muse）
- B 指纹登记簿：核心文件的 SHA-256——MEMORY、口诀总表、炼器六诀、复盘口诀、心流主稿、待办母本、人物索引；只增不改；与盒内指纹双处存照、互相验证
- C 周比对：每周日 19:30，拿最新记忆与 7 天前、30 天前快照逐条对照
- D 判定口径：1 新增内容不管，属正常生长；2 有据变更（有版本锚、当日日志或主人指令可溯）属正常，记一行销掉；3 无据偏差（原有且现存的条目内容变了、又查无出处）属疑点
- E 追溯：疑点再往前 3 天找中间快照比对，定位偏差最早出现的那一天，整理证据链——文件、条目、旧文、新文、日期

- G 边界：巡检只读、只比对、只示警；除登记簿追加与宝盒抄录外，不修改任何记忆文件
